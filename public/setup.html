◈ Dashboard Setup

So wird ein Projekt sichtbar

Das Dashboard scanned automatisch /home/dion/Projekte und die Docker-API (Host-Ports 2000–2999). Neues Repo klonen → Karte erscheint sofort mit Status „unbekannt". Damit echte Daten erscheinen, muss das Repo eine PROJECT_STATUS.md enthalten.

PROJECT_STATUS.md · Format

Frontmatter (YAML) + beliebiger Body. Diese Felder liest das Dashboard:

---
status: planned | in-development | done
progress: 0-100
version: "1.2.3"
tags: [web, docker]
scope: "Kurzbeschreibung was das Projekt ist und wo es steht"
last_updated: "2026-08-13"
next_steps:
  - Login-Flow fertigstellen
  - Tests schreiben
  - README aktualisieren
---

# Weitere Details / Notizen

progress fehlt → keine Bar. version fehlt → Fallback auf package.json-Version.

Template für neue Repos

---
status: planned
progress: 0
version: "0.1.0"
tags: []
scope: "TODO: Kurzbeschreibung des Projekts"
last_updated: "2026-08-13"
next_steps:
  - TODO: erster Schritt
---

# Projektstatus

Agent-Regeln (AGENTS.md)

Copy-paste in die globale ~/.config/opencode/AGENTS.md (oder projektlokal), damit Coding-Agents den Status automatisch pflegen:

## Projektstatus-Pflicht
- Jedes neue Projekt bekommt sofort eine PROJECT_STATUS.md (Template).
- Bei Arbeiten in einem Repo ohne PROJECT_STATUS.md diese zuerst anlegen.
- Todos der Aufgabe in `next_steps` spiegeln; bei Abschluss abhaken und `progress` anpassen.
- Änderungen an PROJECT_STATUS.md committen + pushen (Doku: direct push auf main).
- `last_updated` auf das heutige Datum setzen.

Funktioniert identisch für Claude Code, Codex etc. — die Datei ist agent-agnostisch, nur Markdown.

Port-Ring

Projekte belegen Host-Ports ab 2000 aufsteigend (2000, 2001, …). Das Dashboard zeigt nur Container aus diesem Bereich. Nächste freie Ports stehen in der globalen AGENTS.md. Das Dashboard selbst läuft auf 12345 (System-Port, außerhalb des Rings).

Session-Resume (opencode://)

Der 1-Klick-Link opencode://session/<id> startet Konsole + opencode mit der Session im richtigen Projektordner. Handler: ~/.local/bin/oc-resume + opencode-resume.desktop. Neu registrieren:

xdg-mime default opencode-resume.desktop x-scheme-handler/opencode
update-desktop-database ~/.local/share/applications

Autostart

Chromium öffnet das Dashboard bei jedem Boot via ~/.config/autostart/dashboard.desktop. Container läuft mit restart: unless-stopped.
